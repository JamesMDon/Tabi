# Privacy

Tabi reads open tab URLs only when you activate it. This is required to merge,
sort, and remove exact duplicates.

All processing happens locally. Tabi does not store or transmit browsing data
and has no analytics, advertising, tracking, telemetry, remote code, or network
service.

Tabi's use of information received from Chrome APIs complies with the Chrome
Web Store User Data Policy, including its Limited Use requirements.

Questions can be filed at <https://github.com/JamesMDon/Tabi/issues>.
