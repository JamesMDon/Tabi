# Tabi

<!-- [![Chrome Web Store](https://img.shields.io/chrome-web-store/v/ADDID)](https://chrome.google.com/webstore/detail/ADDID) -->

Tabi makes tabs tidy! :>

Click the icon or press **Alt+T** to:

- **Merge** all windows into current window
- **Sort** tabs alphabetically by URL
- **De-duplicate** identical tabs
- Preserve pins across merges
- Handle incognito separately
- Show results as -X or ✓
